# Security policy

## Supported versions

The latest tagged `0.1.x` release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting form:

https://github.com/kylegrantlucas/reactive-vcr/security/advisories/new

Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. You should receive an initial response within seven days.
